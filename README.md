#  Luck LiFe

I am building an existing productivity web application called "Luck Live".

IMPORTANT:

Do NOT rebuild the application from scratch.

Do NOT remove existing functionality.

Do NOT change the existing layout unless explicitly requested.

I want to preserve the current visual identity.

The dark theme shown in the provided screenshots is the primary visual reference.

The dark theme must remain visually consistent:

- deep dark teal / near-black background

- dark teal cards

- warm gold/orange primary accent

- warm white text

- muted secondary text

- subtle borders

- rounded cards

- clean premium productivity-app aesthetic

Do not randomly change the dark theme colors.

Create a reusable design system with CSS variables/tokens for:

- background

- surface

- card

- primary

- text

- muted text

- border

- success

- warning

- danger

All existing pages must use the same design system.

Keep the current responsive behavior and make sure the application works on desktop, tablet and mobile.
